## 📌 Project Overview

**PlanejAI** is an academic **no-code prototype** designed to explore how AI-assisted tools could help elementary school teachers organize and personalize lesson plans. It was built collaboratively as part of an Information Systems degree project at **Fundação Santo André (FSA)**.

The prototype was created using **Bubble**. This repository serves primarily as project documentation and does not contain a standalone application codebase.

---

## 🎯 Project Goals

- Explore AI-assisted creation of personalized lesson plans.
- Design an accessible interface with teachers' workflows in mind.
- Practice user-centered design and iterative prototyping.
- Evaluate how no-code development can accelerate an early product concept.

## 💡 Prototype Features

The original project documentation describes the following planned or prototyped areas:

- **Lesson-plan generation:** AI-assisted content tailored to lesson needs.
- **User experience:** interface designed for ease of use by teachers.
- **User accounts:** registration and user management flows.
- **Feedback:** collection of user suggestions and evaluations.

These describe the academic prototype's scope; they are not claims of a production-ready service.

## 🛠️ Technologies & Approach

- **Bubble:** no-code web application prototyping.
- **Artificial Intelligence:** lesson-planning assistance concept.
- **UX / UI:** user flows, interface design and usability considerations.
- **Iterative development:** prototype refinement guided by feedback.
